# RateXp survey

Run `bash "<folder>/../../ratexp-cursor.sh" ask`, where <folder> is the folder that holds
this SKILL.md. Then follow what it prints, word for word. Do nothing else, and do not
summarise the session. If the command cannot run, tell the user that RateXp needs this
command to run, and stop. Never ask the survey questions yourself.
